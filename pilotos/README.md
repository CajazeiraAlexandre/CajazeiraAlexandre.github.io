# Pilotos e testes

Ambiente de avaliação de produtos de dados do laboratório (ADR L0017), publicado em <https://cajazeiraalexandre.github.io/pilotos/>.
Gerado por `ferramentas/publicar_pilotos.py` no laboratório — **não editar à mão**: cada pasta é a cópia da página de
um produto (index.html, prévia do link, dados que a página carrega e README). O resto deste repositório (portfólio,
`gerar.py`) não é tocado pelo publicador.

Páginas de piloto ficam fora dos buscadores (`noindex`) e trazem o selo "Versão de teste". O código que refaz cada
número fica no laboratório; produtos que passarem a definitivos vão para o repositório do projeto (ex.: eleicoes).
